Caller x operation matrix of the access control redesign: the target behaviour, copied from
section 2 of the redesign's design document. AccessMatrixIT runs one test per row (and its
caller variants) and column; pending.csv lists the cells that the current code doesn't meet yet.
Keep this table the same as the design's; see docs/development.md, "Access matrix".

Conventions: `own` = a task the caller owns; `foreign` = an existing task of another owner;
`none` = no own task exists. GET columns are the three views MINIMAL/BASIC/FULL. Create success
is 200 (TES). `200[]` = 200 with only the caller's tasks (here: none); `200o` = 200 with exactly
the caller's tasks. SI = GET /service-info with `serviceInfoPublic: true` (default); the token,
if any, is ignored on SI.
